# 葉神經科候診叫號系統｜分階段交付路線圖

最後更新：2026-10-28  
目前基線：桌面程式原型 `c2854ae`

## 核心原則

- 每一階段可單獨使用與驗收；既有診所系統、健保卡與雲端串接不應阻擋前段工作。
- 候診號碼不可變更。過號病人回來時保留原號，改為「回號待叫」，由醫師決定何時叫回。
- 醫師主控一般叫號、回號、重叫與過號；櫃台負責報到與將原號標為回號待叫。
- 公開頁與雲端不得包含姓名、電話、健保卡號、掛號流水號、病歷、病名或處方。
- 外網中斷不能影響現場叫號、候診螢幕與語音。

## 切片 0｜本機雙畫面原型（已完成）

交付：Windows 桌面程式、醫師／櫃台控制台、HDMI 候診大螢幕、繁中語音、本機匿名 JSON 狀態檔。

已驗證：一般叫號會同步更新候診螢幕；過號病人能以原號回號；公開 Cloudflare 頁不讀取本機資料。

限制：未有每日封存／復原機制，單機為主，尚未以診所實際喇叭與 USB 小鍵盤驗收。

## 切片 1｜單機可試營運版

### 目標

一台 Windows 小主機與一台 HDMI 候診螢幕，即可離線完成一個診次。

### 功能範圍

1. **每日診次**：開始、結束、封存當日匿名紀錄；清空資料必須二次確認。
2. **稽核紀錄**：保存時間、號碼、動作與角色（醫師／櫃台），不記錄姓名或病歷。
3. **復原流程**：授權人員可更正誤按過號／誤叫號，並填寫原因。
4. **設備自測**：測試大螢幕、繁中語音、音量與快捷鍵；顯示連線狀態。
5. **快捷鍵設定**：先測診所系統熱鍵，再設定獨立 USB 小鍵盤；不得預設 F8–F11 為正式鍵位。
6. **匿名備份**：寫入主機指定備份資料夾，僅保留號碼、狀態與操作時間。

### 驗收條件

- 拔除外網後仍能新增號碼、叫號、回號、顯示與播報。
- 模擬 30 個號碼、3 個過號、2 次回號後，原號與稽核紀錄正確。
- 重新啟動程式可恢復未完成候診狀態。
- 候診螢幕於 3 公尺可辨識三位數號碼。

### 決策門

通過才進現場試行；未通過只改善單機版，不進雲端。

## 切片 2｜現場試行與設備驗收

### 現場工作

1. 盤點舊叫號器型號與 USB／LAN／RS-232／API 能力；它只作備援，不作上線前提。
2. 確認候診螢幕的 HDMI、內建喇叭，以及 3.5 mm／USB 喇叭備援。
3. 確認既有診所系統的熱鍵，排除衝突後才寫入 USB 小鍵盤。
4. 櫃台與醫師以假號碼做 10 分鐘演練：新增、一般叫號、過號、回號、重叫、人工備援。
5. 非尖峰時段試行一週；斷電或設備異常時，記錄最後叫號並改人工口頭叫號。

### 成功指標

- 醫師按鍵至螢幕更新／播報少於 2 秒。
- 一週內沒有因號碼變更造成回號爭議。
- 預設不列印紙券；有需要的長者才使用可重複使用的大字號碼卡。

## 切片 3｜診所內網多螢幕版

### 目標與設計

- 小主機執行本機服務與 SQLite，成為唯一資料來源。
- 醫師端、櫃台端、候診螢幕可分開電腦，經診所 LAN 以受控裝置連線。
- 即時更新採 WebSocket 或等效內網訊息；資料只含匿名號碼、狀態、時間與操作紀錄。
- 外網中斷不影響內網。主機故障時採書面最後號碼與口頭叫號；UPS 非 MVP 必要設備。

### 驗收條件

- 候診螢幕重新連線後 5 秒內取得正確目前號碼。
- 醫師端與櫃台端同時操作有明確鎖定與稽核，不能覆寫彼此。

## 切片 4｜匿名 QR 雲端候診查詢

### 公開資料契約

只發布以下三個欄位：

```json
{
  "clinicStatus": "open",
  "currentNumber": 14,
  "updatedAt": "2026-10-28T06:46:00+08:00"
}
```

禁止候診清單、姓名、電話、掛號流水號、病名、處方、健保卡與預估看診時間。

### 工作項目

- Cloudflare Pages 公開頁改讀唯讀 API。
- 診所主機只推送匿名快照，使用每台裝置專屬密鑰驗證。
- 雲端失聯時，公開頁顯示最後更新與「以現場螢幕／語音為準」。
- 公開頁不得包含控制按鈕或病患登入。

### 上線前提

完成切片 2 一週試行，並修復 Cloudflare 與 GitHub 的自動部署連線。

## 切片 5｜既有診所系統輔助串接

### 前提

取得系統廠商提供的正式 API、匯出格式或支援文件，以及當日掛號序號的核對方式。

### 導入順序

1. 櫃台手動輸入當日號碼（預設）。
2. 匯入不含個資的當日候診號碼清單。
3. 只接收廠商 API 的「已報到／候診序號」事件。
4. 若舊叫號器有已驗證協定，作為顯示／語音備援。

### 禁止事項

- 不取得 Injection Key、不自行讀健保卡、不保存健保卡號。
- 不以螢幕擷取、鍵盤側錄或資料庫直連方式偷接診所系統。
- 不將病歷、處方或可識別資料同步至 Cloudflare。

## 切片 6｜LINE 與預約（選配）

- LINE 僅供病人／家屬主動加入後的自願式通知；不傳診斷、藥物、檢驗或健保資訊。
- 網路預約只建立預約意向；病人抵達後仍由櫃台確認報到並產生當日候診號碼。
