# 現場候診控制器（本機原型）

這是醫師與櫃台工作流程的離線原型，不是公開網頁的一部分，也不會被 Cloudflare Pages 發布。

## 操作

1. 櫃台只輸入既有掛號系統的「當日候診號碼」，新增為等待中。
2. 醫師完成既有病歷／處方流程後，按 USB 快捷鍵映射的 `F8` 叫一般候診。
3. 未到者按 `F11` 標記過號。病人回來時，櫃台輸入原號並選「過號病人回來」，狀態改為回號待叫。
4. 醫師於適當時機按 `F9`，以原號叫回；不產生新號、不使用奇偶號。

## 雙畫面使用

- 醫師／櫃台使用 `index.html`。
- 同一台小主機以 HDMI 接候診區螢幕，將第二個瀏覽器視窗開在 `waiting-display.html` 並全螢幕顯示。
- 兩頁在同一台電腦、同一個瀏覽器設定檔下，會透過本機資料自動同步目前號碼；候診畫面沒有任何控制按鈕，也不顯示病患資料。
- 這是 MVP 的離線畫面方案。若候診螢幕改接另一台電腦，才需要加入診所 LAN 的本機服務；不必等到雲端串接才可完成第一階段。

## 資料限制

- 僅儲存號碼與狀態於目前瀏覽器的 `localStorage`。
- 不得輸入姓名、電話、健保卡號、身分證號、病名、病歷、處方或其他可識別醫療資料。
- 正式啟用前，必須將狀態改存於診所主機的受控資料庫，並把公共網頁限制為「當前號碼、診次狀態、最後更新」三個匿名欄位。

## 本機啟動

直接以瀏覽器開啟 `index.html` 即可做流程演練。正式診所電腦版本需以受控帳號、自動備份與現場螢幕／語音介面整合後才可使用。
